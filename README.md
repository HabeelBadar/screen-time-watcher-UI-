NOTE: This is for Windows only. One of the apps below are neccesary for the pragram to work.

This is a custom UI for popular Windows screen time apps, which are:

1. Digital Wellbeing for Windows
Link: https://github.com/christiankyle-ching/DigitalWellbeingForWindows
2. ActivityWatch
Link: https://github.com/activitywatch/activitywatch

To set up, you need the latest version of Python (Python 3 or higher) and one of the screen time watchers, preferably ActivityWatch.

This app is compatible with both applications simultaneously.

This program connects to the ActivityWatch port 5600 and uses the data as an API to provide a more user-friendly custom UI.

ISSUES: If there are any issues related to missing data, they can be fixed by editing the program in Notepad and changing the directory to wherever you have the logs and data stored.
